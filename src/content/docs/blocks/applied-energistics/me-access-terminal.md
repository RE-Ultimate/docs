The ME Access Terminal gives you one place to find and use the items stored on a connected ME network. It is useful once your storage spans several cells or inventories.

## Set up and use

Connect the terminal to a powered [ME Controller](/docs/blocks/applied-energistics/me-controller/) and storage, either directly or with ME Cable. An [ME Drive](/docs/blocks/applied-energistics/me-drive/) with a storage cell is a practical starting point. Open the terminal to deposit items and take them back. Search and sort the list to find what you need.

The display can show stored items, craftable items, or both. A craftable entry is a recipe the network knows, not necessarily an item already in storage. Automated crafting needs its own configured equipment and materials.

If the list is empty, check power, cable connections, and the cells in the drive. A terminal does not add storage capacity by itself. For a crafting grid in the same screen, use an [ME Crafting Terminal](/docs/blocks/applied-energistics/me-crafting-terminal/). Search EMI for the installed recipe.
