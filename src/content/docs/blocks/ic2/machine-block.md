The Machine Block is a basic crafting component for IC2 machines. Make it when you are ready to build ore processing or other industrial equipment. It is a casing, not a powered machine: it has no inventory or processing function of its own.

## Make and use it

Smelt iron ingots to make Refined Iron, then arrange eight Refined Iron around the edge of a crafting grid. Leave the center empty. The result is one Machine Block.

The [Macerator](/docs/blocks/ic2/macerator/), [Extractor](/docs/blocks/ic2/extractor/), and [Compressor](/docs/blocks/ic2/compressor/) use this block in their recipes. These machines need other components as well, including an Electronic Circuit. Check EMI for the full recipe and the ingredients available in the pack.

A Machine Block can also be placed in the world, but placing it does not turn it into a working machine. Keep it as an item until you craft the machine you need. For more advanced equipment, the IC2 Advanced Machine Block uses this casing together with other processed materials. The two casings are different ingredients, so check which one a recipe requests.
