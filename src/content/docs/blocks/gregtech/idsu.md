The Interdimensional Energy Storage Unit, or IDSU, shares one EU store with other IDSUs linked to the same player. It can connect power systems across dimensions without a cable between the units. Each player-linked store holds up to 1,000,000,000 EU.

## Link the units

Place an IDSU and open its window. The first player to access an unlinked unit sets its player ID. Open each unit with the same player to connect it to the same store. The window shows the ID and stored energy. Check the ID before you connect a valuable power supply.

The unit accepts up to 2,048 EU per packet and outputs 2,048 EU per packet. Use cables, transformers and machines rated for that voltage. The output face is distinct from the input faces. Use a wrench to change the facing and check the connection before you energise it.

## Use the window

The upper item slot charges compatible electric items. The lower slot discharges them into the store. The four slots at the right correspond to worn armour. The window also shows current energy and input and output limits.

Units with the same ID draw from the same reserve. A remote machine can therefore drain energy needed elsewhere. Monitor the reserve and use transformers where a destination needs a lower voltage. The pack enables the IDSU recipe and uses Adjustable Energy Storage Units in it.
