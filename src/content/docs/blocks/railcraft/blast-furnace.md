The Railcraft Blast Furnace turns iron ingots into steel. It is useful when you need steel for Railcraft equipment and other pack recipes.

## Build and use

Build a solid 3 × 3 base of Blast Furnace blocks. Add two hollow 3 × 3 layers, then finish with a solid 3 × 3 top. Leave the two center spaces between the base and top empty. This uses 34 blocks and makes a structure four blocks tall. Use EMI to find the installed block recipe.

Open the completed furnace. Put iron in the input slot and charcoal or coal coke in the fuel slot. Take steel from the output slot. It does not need MJ, EU, or a water supply. A [Coke Oven](/docs/blocks/railcraft/coke-oven/) can make coal coke for it.

## Troubleshooting

Ordinary coal is not a valid fuel for this furnace. Check that the fuel is charcoal or coal coke, that the structure is complete, and that the output slot has space. Processing takes time, so make more than one furnace if steel production cannot keep up.

This is Railcraft's furnace, not the separate GregTech multiblock. Use EMI to check which steel-related recipes and machines your next item needs.
