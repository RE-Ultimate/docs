The Coke Oven makes coal coke from coal. It also turns logs into charcoal. Both processes produce creosote oil. Build one early if you need fuel for a [Blast Furnace](/docs/blocks/railcraft/blast-furnace/) or creosote for rail materials.

## Build and use

Make 26 Coke Oven blocks. Arrange them as a 3 × 3 × 3 cube with the center empty. Open the completed oven and put coal or logs in its input slot. The oven does not need a separate fuel supply or power connection.

Collect the solid output from its output slot. Remove creosote with a suitable empty liquid container or a liquid transport connection. Check EMI for the oven blocks and the installed recipes.

## Keep it working

The oven works slowly. It stops when there is no room for the next solid output or the creosote tank cannot accept the next liquid output. Empty both outputs if the progress stops. Several ovens can produce fuel in parallel when one is too slow.

Coal coke is a furnace fuel and a valid Blast Furnace fuel. Creosote is a separate liquid, so a chest cannot collect it. Plan liquid storage or use containers to clear the internal tank.
