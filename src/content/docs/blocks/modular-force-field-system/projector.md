The MFFS Projector creates a force field with a shape module. It is a useful part of a modular barrier around a base or another area. The projector needs a valid field type and a force energy source before it can maintain a field.

## Set up a field

Place the projector where the chosen field shape will work. Open its window and add a projector type module. Different modules produce different shapes, including a cube, sphere, wall, and tube. Link the projector to an MFFS power source with a power link card. The window shows the link state and available power.

Turn on the projector after the module and power link are in place. If it does not start, check the type slot and the power link first. The field stops when its type or power source is no longer valid, or when available force energy is too low. The field also stops when the projector is switched off.

## Adjust the field

The projector has slots for focus matrices and field modulators. Their effects depend on the selected type module. Add compatible options only after choosing a type and connecting power. Some options cannot be combined, and the projector rejects unsupported items.

Plan an entrance and test the field before enclosing a work area. A security link and suitable options can change access or field behavior. Check the module and card recipes in EMI, because this version uses the MFFS force energy system alongside IC2.
