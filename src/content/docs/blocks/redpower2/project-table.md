The Project Table combines a crafting grid with storage for ingredients. Use it for recipes you repeat while building machines and components.

## Use

Open the table and arrange ingredients in the crafting grid. Take the result as you would from a crafting table. Store extra ingredients in the table inventory to keep them close to the grid; the table can refill ingredients from its storage as you craft.

The table also has a plan slot. It is a manual crafting station, so it needs neither fuel nor blutricity. Check EMI for the installed recipe and ingredient uses. If a recipe does not produce a result, check the grid and available ingredient quantities.
