The Alveary is an advanced bee housing made from multiple Forestry blocks. It supports a colony like an [Apiary](/docs/blocks/forestry/apiary/) and can use special components to change its environment.

## Before building

Start with an Apiary and a working bee supply. The Alveary needs more resources and construction space, so it is useful after you have started breeding and can make its components. Check EMI for the Alveary blocks and their installed recipes.

For a basic housing, build a solid 3 × 3 × 3 cube of 27 plain Alveary blocks. Cover it with a 3 × 3 layer of bottom-half slabs. Do not leave a hollow center. This Forestry 2.0 structure does not require stairs.

Special Alveary components can replace some plain blocks. Keep the center and the four edge centers of the upper cube layer plain. Start with the plain structure, confirm that it forms, then add components in the allowed positions.

Once formed, add a princess and drone and collect the queen's products and offspring. Bee traits and environmental conditions still matter. Heater, fan and humidity components can change the environment, but their presence does not make every species work in every location. Check the housing and bee conditions before adding more equipment.
