The Squeezer extracts liquid from solid items. Build one early for seed oil, which the [Carpenter](/docs/blocks/forestry/carpenter/) uses to make impregnated casings.

## Setup and use

Supply BuildCraft-compatible MJ power and put a valid ingredient in the input. Ordinary seeds, pumpkin seeds and melon seeds can produce seed oil. Apples produce juice and can also produce mulch. Look up other installed recipes in EMI.

Collect the liquid from the output tank with a compatible container or a liquid connection. Collect any solid remnants from their output slot. A remnant can be chance-based, so one is not guaranteed for every item.

The tank holds one liquid at a time. Empty it before switching to a recipe with a different liquid. If production stops, check the power, the input recipe, the liquid tank and the space for solid output. Save mulch for the [Fermenter](/docs/blocks/forestry/fermenter/) if you plan to make biomass.
