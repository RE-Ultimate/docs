The Quarry builds a frame and mines the area below it using Minecraft Joules (MJ). It is useful for collecting large amounts of stone and ores, but needs a steady power supply and space for the results.

## Set up

Choose a site where mining is safe. Use BuildCraft landmarks to define the area if the default area is unsuitable, then place the Quarry beside the marked boundary. Supply MJ and allow it to build its frame before the mining head begins work.

Connect an inventory or item transport to collect the mined items. Provide enough storage and check the output path during the first run. A blocked or inadequate collection system can leave items in the world.

The Quarry changes a large area and can encounter caves and liquids. Inspect the site and its surroundings before starting, especially near builds. Use EMI to check the installed crafting recipe. This legacy BuildCraft machine uses MJ rather than RF.

The pack enables GregTech’s quarry recipe change. It uses an advanced circuit and a diamond drill with BuildCraft gears.
