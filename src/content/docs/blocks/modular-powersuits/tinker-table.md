The Power Armor Tinker Table configures Modular Powersuits equipment. Use it to install modules on power armor and the Power Tool, adjust their settings, or salvage installed modules. The table works with equipment in your inventory.

## Install a module

Place the table and open it with a Modular Powersuits item in your inventory. Select the item in the left side of the window, then select a module. The install area shows its required components. Keep those components in your inventory and choose **Install**. The selection and available modules depend on the item you choose.

Some modules add protection, power storage, movement or tool functions. Powered functions need energy stored in compatible equipment. Install a battery module and charge the equipment before relying on those functions. Check each module's cost and description in the table before spending materials.

## Adjust and salvage

Select an installed module to see its adjustable properties. The sliders can change performance, energy use or weight, depending on the module. Review the displayed values before leaving the table. The salvage control removes a selected installed module. Check the result before relying on recovered components.

The pack disables the mod's built-in recipe sets and supplies its own recipes through a script. The table needs a computer monitor, advanced circuits, refined iron, an emerald and an advanced machine component. Several positions accept ore dictionary alternatives. Check EMI for accepted ingredients and for the component recipes, which use GregTech progression.
